# CRM — закупочная стоимость материалов

Добавлено:
- в складе поле «Закупочная цена»;
- для ПВХ полотна закупочная цена считается как ₽/м²;
- для остальных материалов — ₽ за пог.м/шт;
- таблица склада показывает закупочную цену;
- расчет обрезков теперь считает:
  стоимость обрезков = (площадь погонажа − площадь деталей с офсетом) × закупочная цена м² ПВХ;
- если в заказе используется несколько ширин ПВХ, берется средневзвешенная закупочная цена по площади.

Перед использованием запусти SQL:
