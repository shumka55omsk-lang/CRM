# CRM — видимый блок стоимости обрезков

Исправлено:
- блок «Стоимость обрезков» вынесен отдельной оранжевой панелью;
- добавлена крупная галочка «Учитывать стоимость обрезков в итоге заказа»;
- отдельно показываются:
  - площадь погонажа;
  - площадь деталей с офсетом;
  - площадь обрезков;
  - стоимость обрезков;
- если галочка выключена, стоимость показывается справочно;
- если включена, стоимость добавляется в итог заказа.
