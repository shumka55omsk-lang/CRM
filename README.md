# CRM — новая логика ширины окантовки

Изменено:
- видимая окантовка на схеме считается от офсета:
  видимая окантовка = офсет + 0.5 см;
- ширина полосы окантовки для склада/закупа:
  полоса = офсет × 2 + 1 см;
- пример:
  офсет 4.5 см → полоса 10 см → на схеме окантовка 5 см;
  офсет 3.5 см → полоса 8 см → на схеме окантовка 4 см;
- строка закупа окантовки теперь меняет ширину автоматически.
