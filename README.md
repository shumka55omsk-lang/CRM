# CRM мягких окон — фактическая экономика фурнитуры

Версия собрана от текущей рабочей ветки `main` репозитория CRM.

Изменено:
- коэффициент 1,6 для открывающихся окон удалён;
- ремни, молния, люверсы 10 мм и овалы 42×22 считаются по фактическому количеству;
- к закупочной цене фурнитуры добавлена стоимость её установки;
- монтаж на объекте считается отдельно: площадь × стоимость монтажа за м²;
- добавлен блок «Экономика заказа»: материалы, фурнитура, работа, монтаж, себестоимость, прибыль и маржинальность;
- фурнитура включена в закуп и списание со склада;
- клиентский документ не показывает внутреннюю себестоимость.

## Однократное обновление Supabase

Выполните содержимое `sql/stock_installation_cost.sql` в Supabase SQL Editor. Скрипт только добавляет поле стоимости установки в существующую таблицу `stock_items`, не удаляя и не изменяя имеющиеся данные.

До выполнения SQL стоимость установки продолжает работать, но сохраняется локально только на текущем устройстве.
