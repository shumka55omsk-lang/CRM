# CRM — люверсы, двери и исправление печати раскроя

Изменено:
- исправлены пустые листы при печати листов раскроя;
- добавлена отдельная галочка «Люверсы / открывается»;
- для открывающихся окон на люверсах добавлена разметка креплений на двух боковых сторонах и снизу;
- расстояние между люверсами не более 40 см, промежутки равные;
- для открывающихся окон применяется наценка +60%;
- добавлена галочка «Дверь»;
- для двери применяется коэффициент сложности ×2.5;
- разметка люверсов отображается на схемах и в задании производства.
