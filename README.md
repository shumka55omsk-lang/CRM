# CRM — зеркалирование трапеций в раскладке рулона

Изменено:
- если проём имеет наклонную сторону/трапецию и деталь поворачивается при раскладке на рулоне,
  CRM зеркалит её по вертикали;
- это нужно, чтобы к левому краю рулона примыкала ровная сторона, а не наклон;
- правило применяется к SVG раскроя и к схеме раскладки в задании производства;
- в подписях деталей добавляется отметка «зеркально».
