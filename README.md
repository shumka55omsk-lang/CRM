# Исправление раздела «Производство»

Раньше вкладка «Производство» показывала только клиентов со статусами:
- Предоплата
- В производстве
- Монтаж

Если заявка была заведена, но статус оставался «Новая заявка» или «Расчёт отправлен»,
раздел был пустой.

Теперь раздел «Производство» показывает:
- клиентов со статусами Предоплата / В производстве / Монтаж;
- клиентов с сохранённым расчётом, если заказ ещё не завершён и не отказ.
