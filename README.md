# CRM — листы раскроя в задании производства

Изменено:
- в HTML «Задание в производство» добавлен раздел «Листы раскроя для печати»;
- раскрой выводится на отдельных листах;
- на каждом листе размещается до 2 проёмов/деталей;
- у каждой детали указаны: окно, деталь, рулон, размер резки, погонаж, ориентация;
- добавлены размерные подписи на схеме раскроя.
