- кнопка «HTML для клиента» открывает документ в новой вкладке;
- кнопка «Задание в производство» открывает документ в новой вкладке;
- кнопка «Договор + акт» открывает документ в новой вкладке;
- в каждом открытом документе сверху есть кнопка «Сохранить HTML».
