# CRM — оптимизированная раскладка на рулонах

Добавлено:
- при наличии сначала выбираются рулоны 2.2 и 2.4 м;
- если 2.2/2.4 нет, используется 1.8 м;
- детали укладываются рядами по ширине рулона;
- если две детали с офсетом помещаются по ширине рулона, они кладутся рядом;
- расход погонных метров считается по фактической высоте рядов раскладки;
- SVG-раскрой использует ту же раскладку, что и расчёт закупа.
