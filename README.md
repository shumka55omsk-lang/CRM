# CRM — выбор рулона с учетом склада

Исправлено:
- выбор рулона теперь учитывает наличие на складе;
- если 1.8 м нет, но 2.2 м или 2.4 м есть, CRM выбирает имеющийся рулон;
- для деталей с габаритом до 2.0 × 2.1 м применяется правило разворота поперек рулона 2.2/2.4;
- ширины склада нормализуются: 2,2м = 2.2 м.
