# CRM — исправление SVG раскроя для большого количества проёмов

Исправлено:
- кнопка «Скачать раскрой SVG» теперь формирует один общий SVG-файл со всеми деталями заказа;
- раньше при раскладке на разные ширины рулона браузер мог скачать/показать только часть файлов, из-за чего казалось, что на холсте только 3 проёма;
- в SVG добавлен контроль: «Всего деталей в SVG: N из M»;
- в задании производства добавлен счётчик деталей на раскладке;
- все рулоны отображаются в одном SVG блоками сверху вниз, с подписью ширины рулона и погонажа.
