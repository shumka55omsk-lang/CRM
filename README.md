# CRM — печать раскроя без пустых листов и новая логика молний

Изменено:
- кнопка «Распечатать листы раскроя» открывает отдельное чистое окно только с листами раскроя;
- это убирает пустые листы при печати;
- если в окне есть молния, расход окантовки увеличивается ×2.5;
- увеличенный расход окантовки учитывается в закупе и стоимости изделия;
- галочка «Дверь» сохранена, но коэффициент удорожания больше не применяется;
- дверь теперь только помечает проём в документах.
