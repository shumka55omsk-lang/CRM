# CRM — печать листов раскроя

Изменено:
- в задании производства на листе раскроя внешний сплошной контур показывает размер резки;
- внутренний пунктир показывает размер светового проёма;
- добавлены подписи размеров резки и светового проёма;
- добавлена кнопка «Распечатать листы раскроя»;
- при нажатии печатаются только листы раскроя, без остальных разделов задания.
