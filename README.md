# CRM — файл раскроя SVG

Добавлено:
- кнопка «Скачать раскрой SVG»;
- формируется отдельный SVG-файл по каждому рулону;
- слои SVG:
  - Резка
  - Контур проема
  - Габариты деталей
  - Рулон
  - Размеры
  - Подписи
- детали размещаются по длине рулона;
- учитывается поворот детали, выбранный логикой закупа.
